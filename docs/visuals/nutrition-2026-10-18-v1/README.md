# Питание: мобильный и настольный макеты

Сгенерированы 18 октября 2026 до реализации раздела. Светлый графитовый текст, белые поверхности, малиновый акцент; тема приложения остаётся независимой от напарника. Открытые списки блюд и две колонки на десктопе, одна на телефоне. Числа и имена на макетах иллюстративны; приложение использует рассчитанные данные и настоящий аккаунт. Девять изображений сервировки сгенерированы отдельно как atlas для реальных карточек, не вырезаны из макетов. Состав проверяется по тексту, изображение его не подтверждает.
