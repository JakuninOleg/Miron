# История MIRON и недостающие ветки CJM

18 октября 2026. Шесть отдельных макетов, созданных встроенным imagegen; [задания генерации](prompts.json). Это иллюстрации проектируемого интерфейса, не скриншоты работающих команд. [CJM и правила глав](../../journey-story.md).

1. [История на десктопе](01-path-desktop.png): самостоятельный раздел рядом с XP, большая сцена и четыре обложки.
2. [История на телефоне](02-path-mobile.png): одна обложка и вертикальный маршрут, будущая глава приглушена, без замка.
3. [Чтение сцены](03-scene-mobile.png): иллюстрация отдельно от доступного текстового диалога, возврат к главам.
4. [После первого занятия](04-next-session-mobile.png): необязательный выбор следующего действия, без обязательной недельной программы.
5. [Исправление подхода](05-correct-set-mobile.png): было/будет, исправление факта отдельно от назначения нагрузки.
6. [Возвращение к занятию](06-resume-mobile.png): продолжить сохранённую сессию, pending sync, честное ожидание подтверждения.

Вёрстка начата с законченного модуля истории: общий переключатель «Опыт и достижения» / «Твоя история», четыре главы, чтение и серверный счётчик разных дней. Он подключён к прогрессу настоящего дашборда и к `/progress`. В публичном `/story/home` доступен пролог с явным статусом дизайн-прототипа; серверные дни не подделываются. Имена глав и условия в HTML берутся из `src/shared/journey-story.ts`, а не из нарисованных надписей.

Отдельные иллюстрации набережной, парка и смотровой оптимизированы в `public/visuals/soft-3d/journey/`; пролог использует уже существующую сцену знакомства. На телефоне сцена читается целиком; на десктопе используется плавное затухание к фону без обрезки волос. При чтении диалог идёт под сценой. Анатомия просмотрена вручную: у каждого героя две руки, без лишней кисти у лица; стоящие фигуры имеют опору и контактные тени.

Макеты 4–6 — следующие ветки разработки; новых команд исправления подходов/повторного открытия завершённой сессии этим модулем не добавлено. Награда +50 на макете — пример полного основного занятия с доступным дневным лимитом, не обещание за любое занятие. Отдельные рисунки упражнений не являются проверенной инструкцией техники.

Иллюстрации глав не содержат пользовательских сообщений. В первом модуле нет обязательной модалки награды, отдельной валюты, потери глав после перерыва, сохранения прочитанного между устройствами или гарантированного офлайн-пакета всех сцен. Право открыть главу одинаково на устройствах и восстанавливается из подтверждённых результатов аккаунта.
