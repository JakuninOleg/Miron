# MIRON: новый экран входа

18 октября: по этим макетам сделан рабочий экран. Актуальные файлы, проверки и отличия от предложения — [реализация входа](../../auth-screen-design.md). Ниже сохранено описание исходного этапа генерации.

18 октября 2026. Два растровых макета для обсуждения. Код авторизации и рабочая страница `/sign-in` этим запросом не изменялись.

- [Десктоп](desktop.png): форма слева, Макс и Лика в мягком 3D справа. Геометрический MIRON без плашки, обычная широкая типографика, без слоганов и текста на персонажах.
- [Телефон](mobile.png): отдельная композиция с обоими персонажами над формой, основные действия видны на первом экране.

Макеты соответствуют прочитанной публичной конфигурации разработки: Яндекс включён, VK выключен, email/password выключен. Условия и конфиденциальность внизу — предложенные места для ссылок, а не утверждение о подключении юридических страниц или согласий. Макеты не заменяют текущий юридический сценарий регистрации.

Встроенный imagegen использовал существующую сцену `public/visuals/soft-3d/scenes/welcome-v2.webp` и `public/brand/{wordmark,mark}.webp` как референсы. Источники — [prompts.json](prompts.json). Десктоп дополнительно отредактирован одним запросом: только текст коралловой кнопки Яндекса изменён с белого на тёмный `#192030`, остальная композиция сохранена. Итоговые изображения просмотрены; проверки браузера не выполнялись, поскольку вёрстка не запрашивалась на этом этапе.
