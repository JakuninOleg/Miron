# Голосовой ввод MIRON

8 октября 2026: запись подключена к `/story/home` и существующему `/chat`. Это реальное распознавание в редактируемый черновик, не подключение Qwen или выполнение тренировочной команды.

## Пользовательский сценарий

Микрофон → разрешение браузера → запись с таймером → остановка → расшифровка → проверка текста → обычная отправка. Запись и обработку можно отменить. Набранный текст сохраняется. При превышении 2000 символов расшифровка предлагается отдельно, без обрезания черновика.

Предел записи — 60 секунд и 5 МиБ. Сеть пропала, напарник изменился, приложение скрыто или микрофон прерван: операция отменяется, дорожки освобождаются, поздний ответ игнорируется. Офлайн микрофон отключён с пояснением. Записи не ставятся в офлайн-очередь, модели на телефон не загружаются. Возвращение сети само запись не запускает.

Браузер использует `getUserMedia` + `MediaRecorder`, проверяет поддержку WebM/Opus, MP4/AAC, Ogg/Opus, при отказе конструктора пробует реальный формат по умолчанию. Нужны разрешение микрофона и HTTPS, кроме доверенного localhost. PWA не отменяет этих требований. Фоновая запись не обещается.

## Серверный маршрут

`POST /api/voice/session` проверяет источник и доступ. `POST /api/voice/transcribe` принимает multipart: `audio`, UUID `operationId`, `companion`, `recordingMs`. Аккаунт определяется по серверной сессии. Заблокированная учётная запись и неподтверждённая почта не получают доступ. Поток ограничен при отсутствии Content-Length; квоты атомарно учитываются в PostgreSQL; ответы не кэшируются.

Локальный прототип имеет отдельный доступ: только `NODE_ENV=development`, loopback и `ENABLE_VOICE_PREVIEW=true`, короткая подписанная HttpOnly/SameSite=Strict cookie на 15 минут. В production этот путь отключён независимо от флага. Он не создаёт аккаунт, trial или приватную историю.

Next передаёт только текущую запись фиксированному внутреннему worker с серверным секретом. Python слушает `127.0.0.1:3075`, проверяет контейнер/кодек, декодирует PyAV в mono 16 кГц и отсекает тишину локальным VAD. Длительность проверяется по сэмплам, не по заголовку; для завершения контейнера допускается одна дополнительная секунда.

Первый маршрут — Groq `whisper-large-v3`, русский язык. При 429, сетевой ошибке, timeout, 5xx или проблеме ключа — заранее прогретый `faster-whisper small`, CPU int8. Неверная запись не обходится повторным распознаванием. При 429 действует ограниченный Retry-After для worker; автоматических повторов Groq нет. Ответ `{operationId,text,provider,model,durationMs}` валидируется сервером и клиентом.

Максимум два активных запроса и один локальный inference, без очереди аудио. Декодер и Groq — ограниченные subprocess, модель — прогретый процесс. Декодирование до 10 с, Groq до 15 с, локальное распознавание до 60 с в общем бюджете 80 с; Next — 95 с, клиент — 100 с. Передача PCM также ограничена 10 с внутри общего бюджета. Отмена/timeout завершает native-процесс и освобождает аудио до восстановления. Одна фоновая попытка прогрева из кэша начинается после 15 с и ограничена 120 с. Неудачная попытка не образует цикл; следующий запрос после cooldown может инициировать новую и получает явную ошибку, пока модель не готова. Загрузка из сети в ходе запроса отсутствует. `/health` защищён; статус Groq отражает конфигурацию/cooldown, не live-проверку.

Стартовые технические пределы: аккаунт 8 записей/мин и 120/24 ч; preview 3/мин и 30/24 ч на cookie; проект 60/мин и 1200/24 ч. Окна отсчитываются от первого запроса, не от полуночи. Это защитные пределы реализации, не утверждённые квоты тарифа. Ключ Go-Ai может делить квоту с другим проектом. Проверка платного entitlement остаётся отдельным требованием выпуска.

## Установка и запуск

Python 3.11 и Node.js 22+, работающая PostgreSQL. Зависимости в `.local/voice/venv`, веса в `.local/voice/models`, оба пути игнорируются Git. FFmpeg отдельно не нужен: библиотеки входят в PyAV.

```powershell
npm run voice:setup
# Заполнить серверные поля .env.local по .env.example.
npm run voice:start
# В другом терминале:
npm run dev -- --port 3074
```

`VOICE_WORKER_SECRET` — общий для Next и worker случайный секрет минимум 32 символа. `GROQ_API_KEY` хранится только в серверном `.env.local`. Для локальной проверки ключ перенесён из Go-Ai без вывода значения; платный аккаунт не создавался. Источник ключа в коде не зашит. После изменения worker или перезапуска компьютера нужно снова запускать `voice:start`; системной службы нет. На Windows launcher останавливает своё дерево процессов.

Для размещения нужны отдельный процесс/контейнер ASR рядом с Next, подготовленный кэш, ограниченные CPU/RAM, защищённый внутренний адрес и проверка `/health`. Задержки нужно измерить на выбранном сервере. Ошибка worker не имитирует удачную расшифровку.

## Данные

MIRON держит аудио только в памяти операции; запись/текст не пишутся в логи, файлы или таблицы ASR. Rate-limit counters содержат владельца и время без содержания сообщения. Groq получает текущую нормализованную запись без профиля и истории. Отмена после отправки не отменяет уже совершённую передачу.

Это не обещание политики хранения внешнего провайдера. [Groq](https://console.groq.com/docs/your-data) отдельно описывает техническое хранение и ZDR; настройки текущей организации не менялись и не подтверждены. До публичного запуска реальные обработчики и потоки отражаются в [юридическом пакете](legal/README.md). Незаполненные реквизиты остаются пустыми; техническая интеграция не утверждает документы.

## Проверки

`npm run typecheck`, `npm run lint`, `npm run test`, `npm run voice:test`, `npm run build`; Playwright `voice-input.spec.ts`, `dashboard-preview.spec.ts`. Проверяются доступ/origin, preview-cookie, поток и квоты, ответ, отмена, поздние чанки, разрешения, потеря сети, формат браузера, лимиты, черновик. Python проверяет реальные MP4/AAC, WebM/Opus, Ogg/Opus, тишину, повреждённые файлы, сэмплы, mock-сбои Groq и зависшие subprocess/IPC. Конкурентность rate limiter проверена на локальной PostgreSQL.

Итог: typecheck, lint и build проходят; Vitest 117 passed / 12 skipped без включения всех DB-сценариев; отдельный PostgreSQL rate-limit suite 2 passed; Python 37 passed; браузерные проверки 18 voice + 5 dashboard + 5 product passed. Офлайн-тренировка проверялась на собранном приложении, не на next dev. Проверка файлов клиентской сборки не обнаружила ключ Groq. Для последнего кода также повторён реальный путь Next → локальный Whisper.

Реальная синтетическая русская запись 7,7 с: «Макс, хочу потренироваться дома. Есть гантели по пять килограммов и сорок минут». Groq вернул верную фразу и числа примерно за 1,5 с; серверный Whisper — за 2,4 с при сетевом отказе основного маршрута. Проверен и HTTP-путь через Next с подписанной preview-cookie. Одна синтетическая запись на компьютере разработки не доказывает качество в зале. Физические Safari/iOS PWA, Android, наушники, звонки и фоновые прерывания ещё нужно проверить на HTTPS-стенде.
