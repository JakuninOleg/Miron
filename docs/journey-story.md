# Твоя история: главы MIRON

18 октября 2026. Продуктовое решение по запросу пользователя: самостоятельная мультяшная история рядом с XP и достижениями. Первое издание — четыре короткие главы. Новая валюта, штрафы за пропуски, обязательные серии и бонусный XP не вводятся.

## Смысл и правила

Человек постепенно открывает маленькие приключения Макса и Лики в большом городе. У каждой главы — собственное место, позы, короткая сцена и диалог. Это художественный контент, не персональное сообщение ИИ и не инструкция по технике. Оба героя участвуют в истории; выбранный напарник продолжает вести личный чат. Чужая личная переписка в сюжет не попадает.

История открывается за **разные дни с подтверждённым результатом занятия**, а не за вес, калории, продолжительность, число подходов, сообщения, оплату или ответы анкеты. Полное и частичное занятие с записанной работой равноправны для истории. Несколько занятий в один день дают один шаг. Дни не обязаны идти подряд; отдых и перерыв ничего не отнимают. Прекращение без записанной работы шаг не создаёт. Это редакционная механика, не требование определённой частоты тренировок.

День закреплён сервером при допуске занятия (`rewardDay`, Europe/Moscow, как действующая политика XP). Для старых записей без него используется дата завершения в той же зоне. Сервер считает все подходящие дни владельца, не только последние 50 строк истории. Локальная очередь не открывает главу до ACK. После синхронизации результат одинаков на устройствах, после выхода и смены героя. Прогресс не зависит от удаления чата. Повторное чтение ничего не начисляет.

Первая глава доступна сразу. Для старого кеша без счётчика показывается просьба обновить прогресс, а не выдуманное число дней. Права на тренировку и смену героя история не меняет. Открытую сцену можно перечитать; финал опубликованного выпуска честно обозначен. Продолжение не обещается к определённой дате.

## Композиция и доступность

В разделе прогресса два переключателя: «Опыт и достижения» и «Твоя история». История — отдельный режим страницы, не модальное меню и не сообщения поверх персонажа. На десктопе крупная текущая обложка и ряд четырёх глав; на телефоне обложка и вертикальный список. Картинки — мягкая 3D-мультипликация с лёгкими рисованными акцентами, без манга-штриховки. Лица и контуры рук не обрезаются. У будущих глав приглушённые обложки, без замков.

Чтение: одна крупная сцена, затем диалог обычным HTML-текстом. Полный текст доступен скринридеру, кнопки — с клавиатуры, переход фокуса — на заголовок сцены/раздела. Без автопрокрутки, мигания, обязательной анимации или звука. На маленьких экранах читатель может прокручивать страницу; это контент, а не форма входа на один viewport.

## Критерии проверки первого модуля

- Серверная изоляция владельцев; полный, частичный, пустой, активный и повторный результат.
- Несколько занятий за день и история длиннее 50 строк не искажают счётчик.
- XP не открывает главы без дней; чтение не меняет XP и достижения.
- Пролог при пустом аккаунте, ясное состояние старого кеша, одинаковые пороги для обоих героев.
- Телефон 320 px, планшет и десктоп; клавиатура, reduced motion, отсутствие наездов на иллюстрацию.
- Независимый Cursor CLI review после модуля правил/данных и после UI; исправления возвращаются на повторный review.

Автоматическое уведомление «новая глава» с сохранением прочитанного на сервере и гарантированная загрузка всех иллюстраций офлайн не входят в первый модуль. Доступность глав уже восстанавливается из серверных результатов; текст сцен поставляется с приложением. Не утверждать, что сцена просмотрена на другом устройстве, пока такого состояния нет.

## Реализация и проверка 18 октября

Подключены `Progress.journey`, серверный агрегат всех подходящих дней, общий каталог четырёх глав и компонент чтения. `ProgressSections` используется в дашборде и на прямом `/progress`; существующие XP, достижения и история сохранены. Новых миграций, платёжных действий и вызовов AI нет. Три новые иллюстрации оптимизированы в WebP, пролог использует существующий ассет. [Макеты и задания генерации](visuals/journey-story-2026-10-18-v1/README.md).

Проверки: `RUN_DB_TESTS=true npm test -- --no-file-parallelism` — 415 passed / 3 skipped; `npm run typecheck`, `npm run lint`, `npm run build` — успешно. Браузерный тест новых глав — реальная локальная БД/auth, два контекста, другой владелец, нулевой XP при четырёх подтверждённых partial-днях, оба маршрута прогресса, фокус и два оформления. Два прежних сценария дашборда Max/Lika также прошли. Размеры коллекции проверены от 320 до 2560 px; реальные устройства iOS этим прогоном не проверялись.

Cursor CLI выполнен в read-only режиме: два прохода правил/данных и три прохода UI. Исправлены замечания про неизвестный счётчик, пустой аккаунт, каскад старых стилей, видимость фокуса, общую навигацию двух маршрутов, обрезку миниатюр и подписи возврата. В финальных отчётах оставшихся actionable findings в проверенном модуле нет. Локальные отчёты: `.local/reviews/journey-domain-v1.txt`, `journey-domain-v2.txt`, `journey-ui-v1.txt`, `journey-ui-v2.txt`, `journey-ui-v3.txt`; они не входят в публичные данные приложения. Сборка и браузерные прогоны выполнены после исправлений. Это не деплой и не подтверждение готовности остальных веток CJM.
