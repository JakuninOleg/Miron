# MIRON: CJM локальной беты

Срез: 18 октября 2026. Исходная [карта пути](user-journey-map.md). Ponytail: используем существующие провайдер, журнал и доменные команды. Каждый модуль проходил Cursor CLI review, исправления и повторную проверку. Продакшен этим этапом не изменялся.

## Работающие пути

- [x] Регистрация → один trial на 168 часов от серверной даты регистрации → onboarding один раз → аккаунтный dashboard. Повторный вход не обновляет trial; возраст и состояние аккаунта проверяются сервером.
- [x] Разовое собственное занятие: место/направление → уместный инвентарь → каталог с фильтрами → именованный шаблон → проверка условий → запуск сессии. Календарь/недельная программа не обязательны.
- [x] Повтор из истории: исходная структура, новые факты, без автоматического переноса прошлых весов. Проведённый план сохраняется отдельным шаблоном.
- [x] Занятие: повторы/вес или длительность по типу упражнения, пары/ограниченные дропсеты, таймеры, переходы, пропуск и досрочное завершение. Таймер и чат не отмечают результат автоматически.
- [x] Тот же аккаунтный чат во время занятия, в раскрывающемся блоке с собственной прокруткой и сохраняющимся черновиком. На телефоне сообщения не перекрывают персонажа; смена напарника заблокирована до закрытия активной сессии.
- [x] Облегчение оставшегося: было/будет → подтверждение с версией → общий журнал. Начатые группы и выполненная работа сохраняются.
- [x] Замена неначатого упражнения: сервер сохраняет движение, формат и основные мышцы, не повышает сложность; проверяет актуальный каталог и инвентарь. Пары/дропсеты не заменяются частично. Отозванный вариант не применяется.
- [x] Исправление подходов и явная отмена последней допустимой записи. Исторические факты редактируются отдельно от текущего журнала. Коррекции не дают XP повторно и пересчитывают приблизительный расход без старой ручной поправки.
- [x] Офлайн/возвращение: журнал владельца в IndexedDB, идемпотентные команды. Конфликт устройств показывает сравнение; перед принятием серверной версии сохраняются локальный снимок и очередь с возможностью экспорта. Автоматического rebase нет.
- [x] Итог complete/partial/aborted: реальный ACK и фактическая награда; неподтверждённый офлайн-результат обозначен отдельно. Четыре оценки нагрузки добровольны и не дают XP. После подтверждения — уровень, достижения/главы, прогресс, сохранить шаблон, вернуться на главную.
- [x] Общие пороги достижений для dashboard/прогресса/итога. Оценка нагрузки после finish ACK не скрывает уже начисленный опыт. Старый неизвестный baseline не выдаётся за новое открытие: показывается доступная глава.
- [x] Четыре сюжетные главы за разные дни подтверждённой работы, без серий/штрафов. Явная отметка прочитанного синхронизируется. Публичные иллюстрации включены в offline shell; отметка требует связи. Ссылка из итога сразу открывает историю.
- [x] `/calendar`: назначить шаблон/исторический план/день программы, перенести, пропустить, убрать, начать. Будущий снимок отдельно от факта. Запуск и привязка занятия атомарны, повтор не создаёт дубль.
- [x] `/nutrition`: блюда с CoFID-источниками, любимые/исключённые продукты, общие идеи дня и замены, собственные блюда. План отдельно от съеденного; приблизительные порции, граммы либо без чисел. Неизвестная ценность не равна нулю. Рецепт/режим не переписывает историческую порцию. [Источники и границы](nutrition-module.md).
- [x] `/settings/memory`: добровольные ты/вы, тон, подробность, эмодзи; общее либо отдельно Максу/Лике. Просмотр/правка/очистка с версиями. Нет скрытого вывода диагнозов/пола/психологического профиля.
- [x] Trial/архив: после expiry сервер закрывает новые занятия/контент, AI/STT и изменение будущего плана. Replay прежнего ACK, история, исправления собственных фактов, экспорт и удаление доступны. Dashboard и внутренние страницы показывают архив, без фиктивной оплаты.
- [x] `/settings/account`: точный срок/остаток ответов, серверный экспорт всего сохранённого аккаунта и локального журнала. Явный scope, лимиты размера/частоты, список разрешённых колонок; без auth-секретов и восстановления удалённого чата из replay-снимков.
- [x] Удаление: свежая авторизация/пароль, слово и явное подтверждение; публичный native endpoint закрыт от обхода. Сервер проверяет реальное удаление. Подтверждённые локальные копии стираются перед POST, чтобы потерянный ACK их не оставлял. Неизвестный результат обозначен; другой владелец не затрагивается.
- [x] `npm run cjm:report -- 30`: агрегат текущей сохранённой когорты — регистрация, onboarding, AI-ответ, первый старт/результат, возврат в другой день, медианное время от регистрации. Без текстов/имён/аккаунтных ID и внешнего tracker. Это проекция сохранённых данных, не неизменяемый analytics ledger.

## Доступ посреди занятия

Локальная бета позволяет закончить **одно уже активное** занятие с конечной закреплённой структурой после expiry. Разрешены факты, исправления, облегчение и безопасное закрытие; запрещены новый старт, рост объёма, AI/STT и произвольные замены. Незапущенное `ready` после expiry не активируется.

Окна 6/48 часов из ADR-0004 были предложением, не принятыми пользовательскими условиями. В бете нет жёсткого временного отсечения разрешённых офлайн-фактов. Платная offline licence с timed lease требует отдельной реализации/политики. Объём ограничен одной сессией; новые тренировки не становятся бесплатными.

## Зависимости публичного выпуска

- Платежи/автопродление/отмена/возврат не подключены: нужны бизнес-маршрут и провайдер. UI прямо сообщает это, списаний и фиктивного успеха нет.
- Юридические документы — черновики с пустыми реквизитами по решению пользователя. Не опубликованы и не записываются как принятые. Нужны реквизиты оператора, окончательные версии и основания передачи провайдерам. Медицинская персонализация питания/памяти не включена; локальная анкета ограничений не отправляется как скрытая медицинская память.
- Питание и синхронизация календаря/памяти требуют сети. Нет offline food queue и client-side ASR. Офлайн остаются загруженное занятие, карточки и его журнал; AI/голос показывают отсутствие связи.
- Push-доставка не подключена. Переключатель хранит явно обозначенное предпочтение, не обещает действующую доставку.
- Реальный Safari/iOS/PWA с фоном, клавиатурой и ограничениями памяти требует проверки на устройствах. Chromium по размерам экрана её не заменяет. Каталог и генеративные иллюстрации не становятся экспертно утверждёнными от этих тестов.

## Проверка

Финальная проверка: **448 passed, 3 opt-in skipped**, **10 browser E2E passed**, `npm run typecheck` и `npm run build` прошли. `npm run lint`: 0 ошибок, два предупреждения о намеренной полной навигации после нового старта/исторического ACK, которая заново гидратирует аккаунтный провайдер. Blanket suppression не добавлялся. Миграции 0018–0023 применены только к `127.0.0.1:55432/miron`; PG-тесты используют отдельные аккаунты и cleanup. Деплой/нагрузочные испытания не выполнялись.

Трассы с session fixtures отключены. Размеры 320/390/768/1440 проверяются на горизонтальное переполнение. Снимки — `.local/previews/`.

Итоговые Cursor reviews: source/corrections, calendar, story reads, memory, lightening, replacements, nutrition, recovery, account/access/delete/export, workout UI и метрики — `None` после исправлений. Замечания и обсуждение решений сохранены локально в `.local/reviews/`; review не заменяет тесты.
