# Финальные сцены знакомства

8 октября 2026. Сцены 06/07 «Готовим твоё пространство» и 07/07 «Готово, напарник!» встроены в существующий `/story`. После «Погнали» открывается `/story/home`; повтор знакомства доступен на главной. Сценарий, сохранение выбранного напарника и семислайдовый порядок сохранены.

Десктоп: крупный текст и управление слева, полноценная иллюстрированная сцена справа. Подготовка показывает сумку, полотенце, диск, гантель и шейкер; завершение — дружеский fist bump Макса и Лики. Рукописные подписи связывают сцены с предыдущими экранами. На портретном телефоне и планшете подготовка использует отдельный вертикальный арт фоном всей сцены: тёмный зал сверху, крупный инвентарь снизу, текст и галочки поверх. Вариант с маленькой встроенной картинкой заменён по замечанию пользователя. Завершение: текст сверху, крупный fist bump и кнопка снизу. Низкие и горизонтальные окна используют более компактные размеры. Общий `StoryHeader` одинаков на всех семи сценах, включая финальную; дополнительные полоски слайдов не дублируются внизу.

Оба напарника используют одну тёмную основу и одинаковую композицию финальных сцен. Розовая заливка, розовые маски по всему экрану, фильтр иллюстраций и отдельное увеличение арта Лики убраны по замечанию пользователя. В подготовке Лики розовые индикаторы, галочки, прогресс и акценты шапки. В завершении — белая кнопка «Погнали», розовая надпись «Мы в команде», корона и акценты шапки. На портретном экране подготовка использует фон всей сцены у обоих напарников, завершение — арт между текстом и кнопкой, как у Макса. Независимые настройки реального аккаунта этим не меняются. Roboto Condensed / Manrope / Neucha и размеры общей шапки соответствуют готовым экранам.

У Лики оба арта заранее загружаются в постоянные слои; смена подготовки на завершение меняет их прозрачность за 280ms на тёмной подложке. Композиция и маски общие с Максом. Reduced motion отключает растворение. Скрытый арт исключён из дерева доступности. Изменения этой правки: `story-finale-screen.tsx` (размер загружаемого арта), `story-finale-screen.module.css` (тёмная основа и точечные акценты) и этот документ.

Анимация подготовки сохранена: четыре декоративных кольца, 2–3 секунды на строку, появление галочек, прогресс и один автоматический переход. Кнопка «Можно без ожидания» удалена по запросу пользователя. Reduced motion отключает визуальное движение и сокращает ожидание. Подписи больше не подразумевают сбор мест занятий, поскольку эта сцена ранее удалена. Программа, оборудование и расписание здесь не рассчитываются; текста «первый план собран» нет.

## Файлы

- `src/components/story-finale-screen.tsx` и `.module.css` — адаптивная композиция, арты, шапка и CTA.
- `src/components/story-preparation.tsx` и `.module.css` — оформление существующей последовательности; таймеры и защита от повторного перехода сохранены.
- `src/components/story-onboarding.tsx` — подключение финальных сцен вместо старого узкого представления; остальные компоненты экранов сохранены.
- `src/shared/story-content.ts` — актуальные пути двух иллюстраций.
- `public/story-finale/preparation-v1.webp`, `finish-v1.webp` — оптимизированные арты, по 1254×1254, около 263 КБ каждый.
- `public/story-finale/preparation-mobile-v1.webp` — отдельный вертикальный фон, 861×1827, 181 КБ. Нативный `picture/source` выбирает его для портретного экрана; на десктопе используется квадратный арт.
- `assets/onboarding/finale/` — три PNG-мастера; `assets/onboarding/finale-v1.prompt.json` и `finale-mobile-v1.prompt.json` — точные промпты, референсы и параметры встроенного image_gen. Исходники пользователя использованы как стилевые референсы, UI и текст набраны кодом.
- `tests/e2e/finale-screen.spec.ts`, `story-header.spec.ts` — обе палитры, адаптация, управление, переходы и одинаковая шапка на семи сценах.

## Проверка и границы

Матрица финальных экранов: 320×568, 375×667, 375×548, 390×844, 440×956, 412×915, 768×1024, 1032×1376, 1376×1032, 1280×800, 1672×941, 2560×1440, 667×375 и 412×375. Проверяются отсутствие прокрутки, заголовки, доступность кнопок, клавиатура, reduced motion, единственный автоматический переход и выход на главную с выбранным напарником. Для портретной подготовки отдельно проверяется, что арт закрывает всю сцену и выбирается вертикальный исходник. Скриншоты сохраняются в `.local/previews/finale-{viewport}-{prepare,finish}-{max,lika}.png`.

Это завершение визуального локального прототипа знакомства. Он сохраняет состояние в preview-хранилище, не вызывает приватные API, не создаёт тренировочную программу, не запускает trial и не записывает серверный профиль. Иллюстрации декоративные, не показывают проверенную технику упражнения. Проверка браузерной адаптации не заменяет будущий тест на реальных устройствах.

Проверки: `npm run typecheck`, `npm run lint` и `npm run build` прошли. `npm test`: 101 тест прошёл, 12 тестов с зависимостью от БД пропущены. `npx playwright test tests/e2e/finale-screen.spec.ts tests/e2e/story-header.spec.ts tests/e2e/story.spec.ts`: 42 теста прошли. Скриншоты вручную просмотрены для десктопа, большого телефона, iPhone SE и планшета, включая фон подготовки и завершение.

После возврата Лики к общей тёмной основе прошли `npm run typecheck`, `npm run lint`, `npm run build` и `npx playwright test tests/e2e/finale-screen.spec.ts`: 28 тестов на 14 размерах. Скриншоты Лики просмотрены для десктопа, большого телефона и iPhone SE. Размеры арта в обеих сценах совпадают с Максом в проверенной матрице; кнопка завершения белая, фон без розовой заливки и фильтра. Эти проверки выполнены в Chromium; проверка на физических iOS/Android устройствах остаётся отдельной задачей.
