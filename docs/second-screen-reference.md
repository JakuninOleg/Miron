# Второй экран знакомства: Макс

Локальная UI-итерация от 7 октября 2026. Просмотр: `/story/max`; обычный переход — с первого экрана `/story`. Меняется только сцена Макса и её подключение к истории. Визуал первого экрана, сцена Лики и дальнейшие шаги сохранены.

## Композиция

На desktop: фирменный wordmark с прорезями, счётчик 02/08, крупное коралловое имя, описание характера и четыре пункта помощи слева; самостоятельный арт Макса в центре; три разные comic-сцены, цитата и короткие заметки справа. В шапке используется одна надпись MIRON, без дополнительной M. Roboto Condensed 900 — выразительные заголовки, Manrope — читаемый текст, Neucha — рукописные заметки.

Бабл — живая HTML-реплика с единым SVG-контуром тела и хвоста. Текст и интерфейс не вшиты в картинки. Новый персонаж сверялся с одобренным изображением первого экрана: доброжелательное лицо, полотенце, чёрная футболка, мягкий свет спортзала.

На телефонах используется отдельный вертикальный арт. Важные элементы помещаются в высоту viewport с учётом safe area: имя, характер, реплика, четыре пункта и обе кнопки. На коротких экранах убирается повторяющийся описательный абзац, пункты сокращаются до заголовков. Боковые comic-кадры остаются desktop-элементом, как в мобильном референсе. Планшеты в портретной ориентации получают крупный арт и пояснения к пунктам; в горизонтальной — desktop-композицию. Экран использует `dvh`, размеры и отступы зависят от доступной высоты.

Вход в сцену — плавный сдвиг и появление; штрих под именем прорисовывается. `prefers-reduced-motion` отключает эти эффекты. Кнопки имеют видимый keyboard focus и высоту не менее 44 px. Навигация использует существующее сохранение состояния preview; двойное переключение блокируется на время перехода.

## Собственные иллюстрации

В `public/story-max/` подключены:

- `desktop-v1.webp` — отдельная широкая сцена Макса.
- `portrait-v1.webp` — вертикальная сцена для телефонов и портретных планшетов.
- `pullup-v1.webp` — турник, тёмные стойки и потолочный свет.
- `towel-v1.webp` — другая поза с полотенцем, окна, город и мягкий вечерний свет.
- `peace-v1.webp` — приветствие двумя пальцами, кирпичная стена и гантельный ряд.

Три боковых кадра — три самостоятельные генерации с разными фонами, позами и ракурсами. Предварительный `panels-v1.webp` не подключён. Промпты и имена исходных генераций сохранены в `assets/onboarding/max-screen-v1.prompt.json` и `max-panels-v2.prompt.json`. Исходники скопированы в проект с WebP-кодированием без изменения рисунка. Это art для знакомства, а не опубликованная инструкция по технике упражнения.

## Границы и проверка

БД, auth, AI, trial, XP и план тренировок этой итерацией не меняются. Прямая ссылка предназначена для локальной проверки и возвращает в общий preview-поток кнопками «Назад» / «Круто, дальше».

Матрица Chromium/Playwright: 320×568, 375×667, 375×548, 390×844, 440×956, 412×915, 768×1024, 1032×1376, 1376×1032, 1280×800, 1672×941, 1920×1080, 2560×1440, 667×375. Проверяются отсутствие прокрутки, размещение заголовков и пунктов, доступность обеих кнопок, смена ориентации, keyboard focus, reduced motion и три разных источника боковых изображений. Сохранены проверки первого экрана и прохождения всей истории. Настоящие устройства Safari/iOS и Android отдельно не тестировались.

Фактически выполнено: `npm run build`, `npm run typecheck`, `npm run lint`, выборочная проверка Prettier; `npm run test` — 94 passed / 12 skipped; Playwright по `first-screen.spec.ts`, `max-screen.spec.ts`, `story.spec.ts` — 33 passed. Пропущенные Vitest-проверки требуют отдельного DB-сценария; миграции в этой итерации не менялись. Скриншоты получены из работающего приложения, отдельно просмотрены desktop, laptop, телефон SE, большой телефон и планшет в обеих ориентациях.

Файлы реализации: `src/components/story-max-screen.tsx`, подключение в `story-onboarding.tsx`, отдельный просмотр `src/app/story/max/page.tsx`. При добавлении сцены Лики общая оболочка вынесена в `story-coach-screen.tsx` / `story-coach-screen.module.css`; композиция Макса сохранена. Новые проверки — `tests/e2e/max-screen.spec.ts`; helper существующих story-проверок учитывает новую подпись кнопки. Исходные файлы первого экрана не редактировались.
