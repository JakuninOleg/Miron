# MIRON — логотип v1

Первый векторный вариант, 6 октября 2026. Основан на двух брендбордах пользователя: бело-розовый знак M из первого и открытая R / O с двумя прорезями из второго. Геометрия построена заново; растровые артефакты референсов не входят в SVG. Это вариант для согласования, не финальная утверждённая айдентика.

## Файлы

- `miron-mark-dark.svg`: белый/розовый знак на тёмный фон.
- `miron-mark-light.svg`: графитовый/розовый знак на светлый фон.
- `miron-mark-mono-dark.svg`, `miron-mark-mono-light.svg`: одноцветные версии.
- `miron-wordmark-dark.svg`, `miron-wordmark-light.svg`: отдельная надпись MIRON.
- `miron-lockup-dark.svg`: горизонтальная комбинация знака и надписи.
- `miron-app-icon.svg`: квадратная иконка с собственным фоном; маску углов задаёт платформа.
- Соответствующие PNG, иконки 16/32/64/192 px и `logo-preview.png`.

SVG надписи содержит геометрические контуры и обводки, не шрифт. Буквы не зависят от установленной гарнитуры. У знака и надписи прозрачный фон; белые варианты предназначены для тёмных поверхностей. Preview содержит только презентационные подписи и не является логотипом.

Цвета этого варианта: графит `#17181B`, белый `#F8F7F5`, розовый `#F27EA8`, участок переплетения `#C6507B`. Палитра рабочая, до согласования. Одноцветный знак сохраняет разделение диагонали и правой стойки. При уменьшении до favicon 16 px потребуется оценка в настоящей вкладке; рендер файла сам по себе не подтверждает узнаваемость.

Не растягивать по одной оси, не менять расстояния между буквами или разрезы независимо. Для маленьких элементов использовать M, для шапки — надпись или комбинацию. Для приложения предусмотреть варианты темы, не привязывать цвет знака к полу/персонажу.

Происхождение референсов — два брендборда пользователя, созданные ранее в ChatGPT. Товарный знак и доступность названия не проверены. Работающие экраны приложения не изменены.

`build.cjs` сохраняет геометрию и формирует производные PNG через bundled sharp; путь среды в нём специфичен для текущей машины. Для интеграции достаточно итоговых SVG/PNG, этот скрипт не является зависимостью приложения.
